# Key Mod

A minimal NeoForge mod for Minecraft 1.21.8. Adds one item, **Key**, using the supplied `key.bbmodel` geometry and texture. It has no special behavior.

## Requirements
- Minecraft 1.21.8
- NeoForge 21.8.54
- Java 21
- Gradle 8.14+ (or open the project in IntelliJ IDEA and import it as a Gradle project)

## Build
Run `gradle build` from this folder. The mod JAR will be created in `build/libs/`.

## Install
Copy `build/libs/keymod-1.0.0.jar` into the `mods` folder of a Minecraft 1.21.8 NeoForge installation.

## In game
Find **Key / Ключ** in the Ingredients creative tab, or use `/give @s keymod:key`.
